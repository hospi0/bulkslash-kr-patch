## 음성 묶음 VCP*.DAT·VCDM.DAT (`tools/vcp.py` → work/vc/*.aif·*.wav, 표 work/vc_table.tsv)
- 섹터 0 = 항목 16 B × N: (u32 BE 시작 섹터, 섹터 수, 자리 크기, **실제 소리 길이**). 시작 0 이면 끝.
- 클립 = AIFF(COMM·MARK «beg loop/end loop»·INST·APPL «ALCHENVS»·SSND), **모노 8비트 22,050 Hz**, 자리 크기까지 0 으로 채움.
  4번째 값 = SSND 안 마지막 0 아닌 바이트 위치(전 592개 일치) → 실제 길이.
- 같은 섹터를 가리키는 항목 있음(VCDM_05·06·07 = 같은 «何やってるの!») → 번역은 섹터 기준 중복 제거.
- 합계 592항목. 받아쓰기 work/asr.tsv(tools/asr_all.py, 위스퍼 large-v3, VAD 끔).

### 내용 (받아쓰기 기준)

- VCPn 번호 = 내비게이터 공통 «칸»(VCP0 기준): 00‥02 발진 · 03‥05 타깃 파괴/확보/세트 · 06 미확인 물체 · 07‥09 · 10‥12 비명 ·
